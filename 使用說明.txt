ZW3D 無用檔案清除程式  v1.6.0
（檔名：zw3d_無用檔案清除程式／原名：檔案管理工具 Folder Manager）
作者：阿家_diabloz
English version: Readme_English.txt

================================================================
一、用途
================================================================
  快速找出電腦裡 ZW3D 產生的暫存檔、備份檔等無用檔案與資料夾，勾選後一次清除。
  也可以一鍵清理 ZW3D 各版本的使用者目錄（output／custom／temp）。

================================================================
二、檔案內容
================================================================
  zw3d_無用檔案清除程式.cmd   雙擊這個檔案啟動程式
  zw3d_無用檔案清除程式.ps1   程式本體（PowerShell 腳本，可用記事本開啟檢閱）
  app.ico                     視窗圖示
  使用說明.txt                本說明（繁體中文）
  Readme_English.txt          英文版說明

  執行後同資料夾會自動產生：
  logs\                       操作日誌（每天一個檔案）
  language.txt                記住你選擇的介面語言與 ZW3D 語言版本

================================================================
三、系統需求
================================================================
  Windows 10 / 11（內建 Windows PowerShell 5.1，不需另外安裝任何東西）

================================================================
四、安裝與啟動
================================================================
  1. 解壓前：對 zip 按右鍵 →「內容」→ 勾選「解除封鎖」→「確定」。
     （可避免每次啟動都跳出「開啟檔案 - 安全性警告」）
  2. 把 zip 解壓縮到任一資料夾（不要直接在 zip 裡面執行）。
  3. 雙擊「zw3d_無用檔案清除程式.cmd」。
     會先閃過一個黑色命令視窗，接著出現「啟動中…」畫面，幾秒後進入主畫面。
  4. 程式已開啟時再點一次啟動檔，會把原本的視窗帶到最前面，不會重複開啟。
  5. 若出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。

================================================================
五、基本操作
================================================================
  1. 左側勾選要搜尋的磁碟機（可多選；「全選/全不選」、「重新整理」可更新清單）。
  2. 輸入關鍵字，或從「常用」下拉選一個；關鍵字留空 = 列出全部（上限 5000 筆）。
  3. 選擇「搜尋對象」：資料夾／檔案／兩者。
     選「資料夾」時「副檔名」欄會停用（資料夾沒有副檔名）。
  4. 選擇「深度」：3／5／8／12 層或不限。層數越少越快。
  5. 「僅顯示 ZW3D 相關」篩選（預設開啟），可選：
     - 全部 ZW3D 檔案（模型＋暫存）
     - 僅 ZW3D 暫存垃圾檔（對應官方 clear ALL.bat）
     - 僅 ZW3D 模型檔（.z3 / .z3prt / .z3asm / .z3drw）
  6. 「副檔名」可選清單中的副檔名或自行輸入；輸入 *、.*、不限、all 視為不限。
  7. 按「搜尋」或在關鍵字欄按 Enter。掃描中可按「停止」。
  8. 勾選要刪除的項目（「勾選全部」／「清除勾選」），按「刪除勾選項目」。
     - 預設移至資源回收筒，可還原。
     - 勾選「永久刪除（不進回收筒）」才會直接刪除，無法復原。
     - 刪除前一律跳出確認視窗，列出所有將被刪除的項目。
  9. 其他按鈕：
     - 檔案總管：在檔案總管中開啟目前選取的項目
     - 日誌資料夾：開啟 logs\
     - 匯出清單：把搜尋結果存成 .txt / .csv / .json
     - 使用者目錄：清理 ZW3D 使用者目錄（見第六節）
     - 立即停止（Ctrl+Q）：中止所有作業並結束程式

================================================================
六、清理 ZW3D 使用者目錄
================================================================
  按「使用者目錄」，程式會自動偵測本機已安裝的 ZW3D 版本，提供與官方
  User Folder Manager 相同的四個動作：
  - 清除自動輸出檔案：刪除 output\（日誌、封存、轉換輸出等）
  - 清除自訂組態：    刪除 custom\（介面組態、範本、授權等，會重置個人設定）
  - 清除暫存檔：      刪除 temp\（工作階段與中繼暫存檔）
  - 清除使用者目錄：  刪除整個版本目錄
  建議先關閉 ZW3D；偵測到 ZW3D 正在執行時會先提醒。

================================================================
七、多國語言
================================================================
  畫面右上方有兩個獨立的語言選單，選擇會自動記住（存在 language.txt）。

  1. 介面語言：切換本程式畫面上的文字，不影響搜尋結果。
     支援 15 種語言：
       中文(繁體)  zh_TW        中文(简体)  zh_CN        English     en_US
       日本語      ja_JP        한국어      ko_KR        Deutsch     de_DE
       Français    fr_FR        Español     es_ES        Italiano    it_IT
       Português   pt_PT        Русский     ru_RU        Polski      pl_PL
       Čeština     cs_CZ        Magyar      hu_HU        Türkçe      tr_TR
     15 種語言皆為完整翻譯：按鈕、選單、提示、狀態列、確認視窗與各對話框標題都會跟著切換
     （操作日誌固定以英文記錄，繁中／簡中介面除外，方便回報問題）。
     每種語言會自動套用合適的字型（例如日文 Yu Gothic UI、韓文 Malgun Gothic），
     視窗標題也會換成該語言的程式名稱（例如英文 ZW3D Junk File Cleaner、
     日文 ZW3D 不要ファイル削除ツール）。

  2. ZW3D 語言版本：告訴程式你的 ZW3D 是哪一種語言版本。
     不同語言版本的 ZW3D，備份／暫存檔的命名不同
     （例如「備份」、「バックアップ」、「Backup」、「Sicherung」），
     選擇後會：
     - 更新「常用」關鍵字清單
     - 搜尋時一併辨識該語言的在地化檔名
     選「全部語言」= 同時辨識所有語言（預設）。
     為了安全，ZW3D 安裝目錄（Program Files、languages\）內的語言資源不會被列入。

================================================================
八、安全說明
================================================================
  - 程式只在本機執行，不連網、不上傳任何資料。
  - 刪除前一律確認；預設移至資源回收筒，可還原。
  - 系統資料夾（Windows、Program Files、使用者設定檔根目錄、磁碟根目錄等）受保護，不會被刪除。
  - 所有動作寫入 logs\，可隨時查核。
  - 可用隨附的 .sha256 檔核對 zip 是否被竄改。

================================================================
九、常見問題
================================================================
  Q：點了啟動檔沒有出現程式？
  A：請先確認有看到「啟動中…」畫面。沒看到的話，多半是安全性警告視窗被蓋在後面，
     請依第四節「解除封鎖」後重新解壓。仍有問題請把 logs\ 的日誌提供給作者。

  Q：搜尋很慢？
  A：減少深度、少勾幾個磁碟機、輸入關鍵字都能加快。程式第一次啟動會在背景
     準備高速搜尋（約 1～2 秒）；日誌中「Search engine: fast」表示使用高速模式，
     「ps」表示電腦政策不允許，已改用一般模式。

  Q：為什麼不是 exe？
  A：把腳本包成 exe 的寫法容易被雲端硬碟與防毒軟體誤判為惡意程式；
     腳本版內容公開、可自行檢閱，功能相同。
